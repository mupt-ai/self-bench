title: "Self-Hosting"
description: "Deploy SelfBench on your own infrastructure."
icon: "server"
---

The reference deployment runs on GCP: Cloud Run serves the API, GKE runs the Temporal worker and Harbor jobs, and Cloud SQL and GCS hold data and artifacts. The infrastructure is in [`infra/`](https://github.com/mupt-ai/self-bench/tree/main/infra).

1. Provision a GCP project, billing, a Terraform state bucket, and Workload Identity Federation for GitHub Actions.
2. Set the Terraform inputs, and store each runtime secret in its own Secret Manager secret.
3. Apply with Terraform, or deploy through the protected GitHub `dev` and `prod` environments.
4. Point your domain at the load balancer, and register the app URL with GitHub OAuth.

Full steps are in the [infrastructure guide](https://github.com/mupt-ai/self-bench/blob/main/infra/README.md). For a local stack, see [Development](https://github.com/mupt-ai/self-bench#development).
