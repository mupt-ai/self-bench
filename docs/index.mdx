SelfBench turns merged pull requests into verified tasks, runs coding agents on them, and compares accuracy with cost. Use the app, the [CLI](/cli), or the [API](/api) for the same loop.

| Stage | Does | CLI | API |
| --- | --- | --- | --- |
| Build | Generate tasks from merged PRs or a described scenario | `generate`, `scenario create` | `…/batches`, `…/tasks/from-scenario` |
| Review | Approve, reject, or revise each task | `task approve`, `task revise` | `…/tasks/{runId}/{taskId}/review`, `…/feedback` |
| Evaluate | Run models and harnesses on approved tasks | `compare` | `…/evaluations/comparisons` |
| Inspect | Scores, failure explanations, fairness audits | `results`, `task explain`, `task audit` | `…/evaluations/results`, `…/explain`, `…/audit` |
| Publish | Release aggregate results on selfbench.dev | `release publish` | `…/releases` |

Start with the [Quickstart](/quickstart), or read [How It Works](/concepts/how-it-works) for the pipeline.
