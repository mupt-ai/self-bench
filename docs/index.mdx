SelfBench helps you find the best models for *your* repository. It turns merged pull requests into tasks with hidden tests, runs coding agents against them, and compares accuracy with model cost. You can keep your dataset private or release aggregate results for a public repository on [selfbench.dev](https://selfbench.dev).

## How It Works

<picture>
  <source media="(prefers-color-scheme: dark)" srcSet="/media/how-it-works-dark.gif" />
  <img src="/media/how-it-works-light.gif" alt="A merged PR becomes a verified task; agents then attempt it and their accuracy is plotted against cost." />
</picture>

SelfBench starts at the commit before a PR's change. An authoring agent creates an instruction, held-out tests, and a reference solution. A task is accepted only after smoke, no-solution, reference-solution, and determinism checks, followed by an independent review. Accepted tasks can run as native [Harbor](https://harborframework.com/) tasks. Read [Task Generation](/concepts/task-generation) for the full pipeline.
