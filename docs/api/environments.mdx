An environment changes every approved task's files the same way and builds each task with the change. Pass its `id` as a condition's `environment` when you [start a comparison](/api/evaluate).

| Method | Route | Does |
| --- | --- | --- |
| `GET`, `POST` | `{repo}/environments` | List environments, or create one and build every approved task in it |
| `GET`, `DELETE` | `{repo}/environments/{id}` | One environment with each task's check, or delete it |
| `POST` | `{repo}/environments/{id}/build` | Build the approved tasks it lacks or that failed |

## Request Body

| Route | Body |
| --- | --- |
| `POST {repo}/environments` | `{ environment: { name, packages?: [{ name, spec, directory? }], files?: [{ path, mode: "replace" \| "append" \| "delete", content? }] }, generation }` |
