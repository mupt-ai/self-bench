---

These take `SELFBENCH_API_TOKEN`, the deployment's own token, in place of an API key.

| Command | Does |
| --- | --- |
| `operator run list` · `operator run show\|cancel RUN_ID` | Generation runs |
| `operator run download RUN_ID OUT.tar.gz` | A batch's Harbor export, checked against its SHA-256 |
| `operator grant create --label TEXT --task ID [--task ID ...] [--days N] [--with-verifier]` | A customer's registry login for accepted tasks' images, shown once |
| `operator grant list` · `operator grant revoke GRANT_ID` | List or revoke grants |

The older top-level `status`, `cancel`, `list`, `download`, and `grant` still work.
