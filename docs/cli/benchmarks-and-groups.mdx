---

Evaluate, inspect, and release commands take `--benchmark ORG/NAME` or `--group SLUG` in place of `--repo`.

| Command | Does |
| --- | --- |
| `benchmarks` · `benchmark add\|show\|tasks\|remove ORG/NAME[@REF]` | Harbor registry datasets |
| `groups` · `group show\|delete SLUG` | Repository groups |
| `group create\|update SLUG --name NAME --member OWNER/NAME [--member ...]` | Pool connected repositories |

Benchmarks are never released.
