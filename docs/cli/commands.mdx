`R` is `--repo OWNER/NAME`. Every command also takes `--org` and `--json`.

## Account

| Command | Does |
| --- | --- |
| `login [--api-url URL] [--no-browser]` | Sign in through the browser; saves a key and the workspace |
| `org` · `org use [NAME]` | Show or change the workspace commands use |
| `whoami` | The signed-in account, its workspaces and roles, and the key's scope |
| `logout` | Revoke the saved key and forget it |

## Credentials

Workspace admins connect the model access and sandboxes everyone's runs use.

| Command | Does |
| --- | --- |
| `credentials` | Saved credentials, with the IDs flags take |
| `credential add` | Pick a provider, then paste its key (masked) or sign in |
| `credential add --kind KIND (--value-env VAR \| --value-stdin) [--name NAME]` | Add a key without prompts |
| `credential add --sign-in chatgpt\|claude\|meta` | A ChatGPT, Claude, or Meta sign-in |
| `credential rename ID NAME` · `credential remove ID` | Rename or remove one |

`KIND` is `openai`, `anthropic`, `meta`, `openrouter`, `vercel-ai-gateway`, `dari`, `custom` (with `--endpoint`), `e2b`, `modal` (with `--token-id`), `daytona`, or `vercel` (with `--team-id` and `--project-id`). Secrets never go in an argument, so they stay out of shell history.

## Build

| Command | Does |
| --- | --- |
| `repos` | Connected repositories and evals |
| `repo connect\|show\|disconnect OWNER/NAME` | Connect, read, or disconnect a repository |
| `repo set OWNER/NAME --agent-minutes N` | How long an evaluated agent may work on each task |
| `eval create NAME` | Create a workspace eval, then use `--repo evals/NAME` |
| `prs R [--page N]` | Merged pull requests |
| `generate R --easy N --medium N --hard N [--focus TEXT]` | Start a batch that picks PRs and authors tasks |
| `task add-pr R --pr NUMBER\|URL` | Author a task from one merged PR |
| `scenario create R --title T (--scenario TEXT \| --scenario-file F) [--commit REF] [--attach F ...] [--difficulty D]` | Author a task from a described scenario |
| `batches R` · `batch show\|cancel RUN_ID R` | Follow or stop batches |

`generate`, `task add-pr`, `scenario create`, and `task revise` take the generation settings `--model`, `--verifier-model`, `--reasoning`, `--model-credential`, `--sandbox`, `--sandbox-credential`, `--harbor`, and `--harbor-credential`, or `--generation JSON|@FILE`. Without them, they use managed models and sandbox.

## Review

| Command | Does |
| --- | --- |
| `tasks R [--state S]` | List tasks; `S` is `needs_review`, `accepted`, `rejected`, `in_progress`, `failed`, or `cancelled` |
| `task show RUN_ID TASK_ID R` | A task, its review, cost, and revisions |
| `task pull RUN_ID TASK_ID [DIR] R` | Download its files: instruction, Dockerfile, patches, scripts, `workspace/` |
| `task revise RUN_ID TASK_ID R (--feedback TEXT \| --feedback-file F) [--draft DIR]` | Start a revision from your feedback, and your edited files with `--draft` |
| `task approve\|reject RUN_ID TASK_ID R [--note TEXT]` | Review it; only approved tasks are evaluated |
| `task unreview\|cancel\|delete RUN_ID TASK_ID R` | Clear the review, stop its generation, or delete it |

## Evaluate

| Command | Does |
| --- | --- |
| `catalog R` | Models available for evaluations |
| `compare R --model ID [--model ID ...]` | Run each model on every approved task |
| `comparisons R` · `comparison show\|resume\|cancel ID R` | Follow, resume, or stop comparisons |
| `runs R` · `run show\|cancel\|delete EVALUATION_ID R` | One model's evaluation, with every trial |

`compare` options:

| Flag | Default |
| --- | --- |
| `--harness H` (repeatable): `pi`, `codex`, `claude-code`, `mini-swe-agent`, `terminus-2`, `muse-code` | `pi` |
| `--thinking LEVEL`: `off`, `minimal`, `low`, `medium`, `high`, `xhigh`, `max` | the model's default |
| `--credential ID` | managed model |
| `--sandbox managed\|e2b\|modal\|daytona` and `--sandbox-credential ID` | managed sandbox |
| `--task RUN_ID/TASK_ID` (repeatable) | every approved task |
| `--skip-completed` | rerun everything |
| `--judge-credential ID` | needed for tasks graded by an LLM judge |
| `--selection JSON\|@FILE` | a full [comparison body](/api-reference/create-comparison) in place of the flags |

## Inspect

| Command | Does |
| --- | --- |
| `results R` | Pass rate and cost per task for each configuration, and every task, hardest first |
| `task results RUN_ID TASK_ID R` | Every configuration's result on one task, why each failure failed, and its fairness verdict |
| `task explain RUN_ID TASK_ID R [--config KEY] [--model M --credential ID] [--wait]` | Explain the task's unexplained failures (or one configuration's) |
| `task audit RUN_ID TASK_ID R --model M --credential ID [--wait]` | Judge whether the task is fair from its failures: `fair`, `unfair`, or `unclear` |
| `summaries R` | The latest Model Summaries report |
| `summaries create R --model M --credential ID [--config KEY ...] [--wait]` | Summarize how configurations differ; all of them (up to 12) by default |

`task explain` uses a managed model when the deployment offers one. Audits and summaries need a saved model API key.

## Publish

| Command | Does |
| --- | --- |
| `release preview R` | The settings, tasks, and coverage a release would publish |
| `release publish R [--setting KEY ... \| --all-settings] [--publish-tasks] [--publish-trials] [--publish-summaries]` | Release the preview it just read; the app's default settings unless named |
| `releases R` · `release withdraw RELEASE_ID R` | List or withdraw releases |

Only public repositories and groups of them can be released.

## Benchmarks and Groups

| Command | Does |
| --- | --- |
| `benchmarks` · `benchmark add\|show\|tasks\|remove ORG/NAME[@REF]` | Harbor registry datasets; evaluate one with `--benchmark ORG/NAME` |
| `groups` · `group show\|delete SLUG` | Repository groups; evaluate or release one with `--group SLUG` |
| `group create\|update SLUG --name NAME --member OWNER/NAME [--member ...]` | Pool connected repositories |

## Operator

These take `SELFBENCH_API_TOKEN`, a deployment's own token, in place of an API key.

| Command | Does |
| --- | --- |
| `status\|cancel RUN_ID` · `list` | Generation runs |
| `download RUN_ID OUT.tar.gz` | A batch's Harbor export, checked against its SHA-256 |
| `grant create --label NAME --task ID [--task ID ...] [--days N] [--with-verifier]` | A customer's registry login for accepted tasks' images, printed once |
| `grant list` · `grant revoke GRANT_ID` | List or revoke grants |
