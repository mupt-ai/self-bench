```bash cURL
    "models":[{"catalogId":"<catalog-id>","credentialId":"<uuid>","harnesses":["codex"]}],
    "sandbox":"e2b","sandboxCredentialId":"<uuid>"}'
```

A **benchmark** is a dataset from Harbor's registry that the workspace added, evaluated apart from any repository. Adding one downloads and safety-checks every task, and refuses a dataset with a task that fails the check or more than 500 tasks. Every comparison runs the tasks as frozen when the dataset was added.

| Method | Route | Does |
| --- | --- | --- |
| `GET` | `/api/orgs/{org}/benchmarks` | The workspace's benchmarks and whether each is `adding`, `ready`, or `failed` |
| `POST` | `/api/orgs/{org}/benchmarks` | Add one: `{ "reference": "org/name" }`, or `org/name@ref` to pin a version |
| `GET` | `/api/orgs/{org}/benchmarks/registry` | Harbor registry datasets to choose from |
| `GET`, `DELETE` | `/api/orgs/{org}/benchmarks/{dataset-org}/{dataset}` | Read or remove one |
| `GET` | `…/{dataset-org}/{dataset}/tasks` | Its tasks |

Every [evaluation](/api-reference/create-comparison), [results](/api-reference/results), and [failure analysis](/api-reference/failure-analysis) route works under `/api/orgs/{org}/benchmarks/{dataset-org}/{dataset}` in place of a repository. Benchmarks are never released.

## Repository Groups

A group evaluates and releases several connected repositories together, over all their approved tasks. Its results count its members' own runs too.

| Method | Route | Body | Does |
| --- | --- | --- | --- |
| `GET` | `/api/orgs/{org}/groups` | | Groups, and connected repositories with their `id` |
| `POST` | `/api/orgs/{org}/groups` | `{ name, slug, description?, repositoryIds }` | Create one (`repositoryIds` from the list) |
| `GET`, `PUT`, `DELETE` | `/api/orgs/{org}/groups/{slug}` | as for create | Read, edit, or delete one |

Evaluation, results, failure analysis, and [release](/api-reference/publish-release) routes work under `/api/orgs/{org}/groups/{slug}`.
