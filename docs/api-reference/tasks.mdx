Every route is under `{repo}/tasks`, where `{repo}` is `/api/orgs/{org}/repos/{owner}/{name}`.

| Method | Route | Body | Returns |
| --- | --- | --- | --- |
| `GET` | `/tasks` | | `{ tasks }` |
| `GET` | `/tasks/{runId}/{taskId}` | | `{ task, revisions }`, with its generation cost |
| `GET` | `/tasks/{runId}/{taskId}/draft` | | Its files as `.tar.gz`, with `X-Content-SHA256` |
| `GET` | `/tasks/{runId}/{taskId}/artifacts` | | Its gate logs, review, and verification artifacts |
| `PUT` | `/tasks/{runId}/{taskId}/review` | `{ "decision": "approve" \| "reject", "note": "…" }` | `{ task }` |
| `DELETE` | `/tasks/{runId}/{taskId}/review` | | `{ task }`, back to `needs_review` |
| `POST` | `/tasks/{runId}/{taskId}/feedback` | `{ "feedback": "…", "draft": "<base64 tar.gz>", "generation": { … } }` | `201` with the revision's `{ task }` |
| `POST` | `/tasks/{runId}/{taskId}/cancel` | | `202` while it stops |
| `GET` | `/tasks/{runId}/{taskId}/variants` | | `{ variants }`, oldest first |
| `POST` | `/tasks/{runId}/{taskId}/variants` | `{ "variant": { "label": "…", "packages": […], "files": […] }, "generation": { … } }` | `201` with `{ variant }`; `409` unless the task is accepted |
| `POST` | `/tasks/{runId}/{taskId}/variants/{variantRunId}/cancel` | | `202` while it stops |
| `DELETE` | `/tasks/{runId}/{taskId}/variants/{variantRunId}` | | `{ "deleted": true }`; `409` while it is checked |
| `DELETE` | `/tasks/{runId}/{taskId}` | | `{ "ok": true }`; `409` while it is generating |

## States

| `state` | Means |
| --- | --- |
| `in_progress` | Being authored or verified |
| `needs_review` | Passed every gate and the independent review; waiting for you |
| `accepted` | You approved it. Only accepted tasks are evaluated |
| `rejected` | You, or the pipeline, rejected it; `reason` says why |
| `failed` | Infrastructure failed before a verdict |
| `cancelled` | Stopped |

A review needs a settled task (`409` otherwise), and a later review replaces it.

## Revise a Task

Feedback starts a **revision**: a new task whose agent begins from this task's last draft, addresses the feedback, and goes through the gates and review again. The original task and its evaluations stay as they are. The reply's `task` is the revision; it lists the original under `revisedFrom`.

To change the files yourself, download the draft, edit it, and send it back base64-encoded as `draft` (up to 22 MB compressed). The draft holds `instruction.md`, the `Dockerfile`, the patches, scripts, and a workspace scenario's `workspace/`. `generation` is as for [generating tasks](/api-reference/create-batch).

```bash cURL
TASK=https://app.selfbench.dev/api/orgs/acme/repos/acme/app/tasks/batch-1a2b/fix-null-config

curl -X PUT $TASK/review -H "Authorization: Bearer $SELFBENCH_API_KEY" \
  -H "Content-Type: application/json" -d '{"decision":"approve","note":"Tests match the PR."}'

curl -X POST $TASK/feedback -H "Authorization: Bearer $SELFBENCH_API_KEY" \
  -H "Content-Type: application/json" -d '{"feedback":"Also test an empty config file."}'
```
