<ParamField path="org" type="string" required>Workspace login.</ParamField>
<ParamField path="owner" type="string" required>GitHub owner.</ParamField>
<ParamField path="name" type="string" required>Repository name.</ParamField>
<ParamField header="Authorization" type="string" required>`Bearer` plus a `write` API key.</ParamField>
<ParamField body="candidateCounts" type="object" required>Easy, medium, and hard counts; 1–300 total.</ParamField>
<ParamField body="focus" type="string">Which PRs discovery should prefer, in your words.</ParamField>
<ParamField body="generation" type="object">Model, reasoning, sandbox, and credential choices. Required when credential storage is configured.</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://app.selfbench.dev/api/orgs/mupt-ai/repos/mupt-ai/self-bench/batches \
  -H "Authorization: Bearer $SELFBENCH_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"candidateCounts":{"easy":1,"medium":2,"hard":0},"generation":{
    "authorModel":"<model-id>","verifierModel":"<model-id>","reasoning":"medium",
    "modelAccess":"credential","modelCredentialId":"<uuid>",
    "sandbox":"e2b","sandboxCredentialId":"<uuid>",
    "harborEnvironment":"e2b","harborCredentialId":"<uuid>"
  }}'
```
</RequestExample>

Returns `202` with `{ "runId": "batch-…", "run": { … } }`. A batch proposes merged PRs, then authors and verifies each one as a task. It can take hours.

| Method | Route | Does |
| --- | --- | --- |
| `GET` | `{repo}/batches` | The repository's batches |
| `GET` | `{repo}/batches/{runId}` | A batch's progress |
| `POST` | `{repo}/batches/{runId}/cancel` | Stop it and every task it is authoring |
| `GET` | `{repo}/generation-options` | Models, sandboxes, and credentials `generation` can name |

Leave out `generation` to use the managed models and sandbox, where the deployment offers them.

## One Pull Request

`POST {repo}/tasks/from-pr` with `{ "pr": 123, "generation": { … } }` authors one merged PR as a task. `pr` is a number or the PR's URL. It returns `201` with `{ task }`, which appears in [the task list](/api-reference/tasks) in progress. List merged PRs with `GET {repo}/pull-requests?page=1`.
