Results count the same results as the app's chart, model summaries, and releases:

- only **counted tasks**: a repository's accepted tasks, or a benchmark's tasks;
- each configuration's **latest scored result** on each task. A trial is scored when it completed, its model was verified, and it has a reward of 0 or 1 and a cost. Errors, cancellations, and trials still running don't count.

`configurations` sort by pass rate, best first, and `taskResults` by the share of configurations that passed, hardest first. A failed result carries `failureSummary` once [explained](/api-reference/failure-analysis). A configuration's `key` is what [model summaries](/api-reference/failure-analysis#model-summaries) and [releases](/api-reference/publish-release) name it by.

The same route runs under a [benchmark or group](/api-reference/create-benchmark) scope.
