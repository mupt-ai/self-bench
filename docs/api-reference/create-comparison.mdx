title: "Run Evaluations"
api: "POST https://app.selfbench.dev/api/orgs/{org}/repos/{owner}/{name}/evaluations/comparisons"
description: "Run models and harnesses on approved tasks, and follow their evaluations."
icon: "chart-scatter"
---

<ParamField path="org" type="string" required>Workspace login.</ParamField>
<ParamField path="owner" type="string" required>GitHub owner, or `evals`.</ParamField>
<ParamField path="name" type="string" required>Repository or eval name.</ParamField>
<ParamField header="Authorization" type="string" required>`Bearer` plus a `write` API key.</ParamField>
<ParamField body="id" type="string" required>A UUID you generate. Retrying with the same `id` never starts a comparison twice.</ParamField>
<ParamField body="models" type="object[]" required>Up to 12, each `{ catalogId, credentialId, harnesses, thinking? }`. `credentialId` is a saved credential's ID or `managed-model`. `harnesses` are `pi`, `codex`, `claude-code`, `mini-swe-agent`, `terminus-2`, or `muse-code`. `thinking` is `off`, `minimal`, `low`, `medium`, `high`, `xhigh`, or `max`.</ParamField>
<ParamField body="sandbox" type="string" required>`managed`, `e2b`, `modal`, or `daytona`.</ParamField>
<ParamField body="sandboxCredentialId" type="string" required>The sandbox credential's ID, or `managed-sandbox`.</ParamField>
<ParamField body="tasks" type="object[]">`{ runId, taskId }` pairs from `GET …/evaluations/options`. Leave out to run every approved task.</ParamField>
<ParamField body="skipCompleted" type="boolean">Skip tasks each model and harness already completed.</ParamField>
<ParamField body="judgeCredentialId" type="string">A model API key for tasks graded by an LLM judge; required when `GET …/evaluations/options` lists `judge` variables.</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://app.selfbench.dev/api/orgs/acme/repos/acme/app/evaluations/comparisons \
  -H "Authorization: Bearer $SELFBENCH_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"id":"7e0acb2b-3b1e-4df6-8afb-1b0a1cf2d6a8",
    "models":[
      {"catalogId":"gpt-6.1-sol","credentialId":"managed-model","thinking":"high","harnesses":["pi","codex"]},
      {"catalogId":"claude-opus-5-5","credentialId":"managed-model","harnesses":["pi"]}],
    "sandbox":"managed","sandboxCredentialId":"managed-sandbox","skipCompleted":true}'
```
</RequestExample>

Returns `202`. A comparison starts one **evaluation** per model, each running every task on each of its harnesses as a separate trial. If the reply has `submissionError`, resume the same comparison; it reuses the same evaluation IDs.

The same routes run under a [benchmark or group](/api-reference/create-benchmark) scope.

| Method | Route | Does |
| --- | --- | --- |
| `GET` | `{scope}/evaluations/catalog` | Models (`catalogId`), sandboxes, and the managed offer |
| `GET` | `{scope}/evaluations/options` | Tasks a comparison can run, and any judge variables |
| `GET` | `{scope}/evaluations/comparisons` | Comparisons with their progress |
| `GET` | `{scope}/evaluations/comparisons/{id}` | One comparison's progress |
| `POST` | `{scope}/evaluations/comparisons/{id}/resume` | Submit what wasn't confirmed |
| `POST` | `{scope}/evaluations/comparisons/{id}/cancel` | Stop every evaluation in it |
| `GET` | `{scope}/evaluations` | Evaluations with every trial: status, rewards, cost, transcript steps. Sends an `ETag` |
| `GET` | `{scope}/evaluations/{id}` | One evaluation |
| `GET` | `{scope}/evaluations/{id}/artifacts?name=…` | A file a trial's agent left |
| `POST` | `{scope}/evaluations/{id}/cancel` | Stop it |
| `POST` | `{scope}/evaluations/{id}/delete` | Remove it from results; releases that show it keep it |

To read scores, use [Results](/api-reference/results) rather than adding up trials yourself.
