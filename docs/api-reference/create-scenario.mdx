---
title: "Create a Scenario Task"
api: "POST https://app.selfbench.dev/api/orgs/{org}/repos/{owner}/{name}/tasks/from-scenario"
description: "Generate one task from a described scenario, starting from the repository at a commit or from files the author writes."
icon: "notebook-pen"
---

<ParamField path="org" type="string" required>Workspace login.</ParamField>
<ParamField path="owner" type="string" required>GitHub owner, or `evals` for an eval.</ParamField>
<ParamField path="name" type="string" required>Repository name, or the eval's name.</ParamField>
<ParamField header="Authorization" type="string" required>`Bearer` plus a `write` API key.</ParamField>
<ParamField body="title" type="string" required>Up to 120 characters.</ParamField>
<ParamField body="scenario" type="string" required>The change or situation the agent should handle; up to 20,000 characters.</ParamField>
<ParamField body="commit" type="string">Required on a repository, and not allowed on an eval (`400` otherwise). A commit SHA or a branch (`HEAD` for the default branch) the agent starts from; the task is pinned to the commit it resolves to, read with your GitHub sign-in, and an unknown one returns `422`. On an eval, the author writes the files the agent starts with (a workspace scenario) and nothing is read from GitHub.</ParamField>
<ParamField body="difficulty" type="string">`easy`, `medium` (default), or `hard`.</ParamField>
<ParamField body="attachments" type="object[]">Up to 20 files, 20 MB in all, each `{ "name": "export.csv", "content": "<base64>" }`. Names are plain file names.</ParamField>
<ParamField body="generation" type="object">Model, reasoning, sandbox, and credential choices, as for [Create a Batch](/api-reference/create-batch). Required when credential storage is configured.</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://app.selfbench.dev/api/orgs/mupt-ai/repos/evals/data-import-bugs/tasks/from-scenario \
  -H "Authorization: Bearer $SELFBENCH_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"title":"CSV Import Drops Quoted Rows",
    "scenario":"Our CSV import drops rows whose fields contain a quoted comma; my agent split lines on commas.",
    "difficulty":"medium",
    "attachments":[{"name":"export.csv","content":"bmFtZSxjaXR5CiJTbWl0aCwgSmFuZSIsT3NsbwoK"}],
    "generation":{"authorModel":"<model-id>","verifierModel":"<model-id>","reasoning":"high",
      "modelAccess":"managed","sandbox":"managed"}}'
```
</RequestExample>

<ResponseExample>
```json
{
  "task": {
    "runId": "scn-evals-data-import-bugs-…",
    "taskId": "scenario-csv-import-drops-quoted-rows",
    "title": "CSV Import Drops Quoted Rows",
    "difficulty": "medium",
    "state": "in_progress"
  }
}
```
</ResponseExample>

Returns `201`. Follow the task with `GET …/tasks/{runId}/{taskId}`, and [review or revise it](/api-reference/tasks) like any other. Create an eval for workspace scenarios with `POST /api/orgs/{org}/evals` (see [Repositories and Evals](/api-reference/repositories)). See [Author Scenarios](/guides/author-scenarios) for how to write a good one.
