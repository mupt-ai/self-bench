---
title: "Publish a Release"
api: "POST https://app.selfbench.dev/api/orgs/{org}/repos/{owner}/{name}/releases"
description: "Publish a public repository's results on selfbench.dev."
icon: "globe"
---

<ParamField path="org" type="string" required>Workspace login.</ParamField>
<ParamField path="owner" type="string" required>GitHub owner.</ParamField>
<ParamField path="name" type="string" required>Repository name.</ParamField>
<ParamField header="Authorization" type="string" required>`Bearer` plus a `write` API key.</ParamField>
<ParamField body="settings" type="string[]" required>Setting keys from the preview.</ParamField>
<ParamField body="head" type="string | null" required>The preview's `head.id`, or `null` for a first release.</ParamField>
<ParamField body="fingerprint" type="string" required>The preview's `fingerprint`, so only results you previewed are published.</ParamField>
<ParamField body="publishTasks" type="boolean">Also publish each task's instruction, tests, and solution.</ParamField>
<ParamField body="publishTrials" type="boolean">Also publish each setting's result and redacted transcript on each task. Needs `publishTasks`.</ParamField>
<ParamField body="publishSummaries" type="boolean">Also publish the latest [model summaries](/api-reference/failure-analysis#model-summaries) of the released settings.</ParamField>

<RequestExample>
```bash cURL
BASE=https://app.selfbench.dev/api/orgs/acme/repos/acme/app/releases
PREVIEW=$(curl -s $BASE/preview -H "Authorization: Bearer $SELFBENCH_API_KEY")

curl -X POST $BASE -H "Authorization: Bearer $SELFBENCH_API_KEY" \
  -H "Content-Type: application/json" \
  -d "$(echo "$PREVIEW" | jq '{settings: [.preview.settings[] | select(.ticked) | .key],
    head: .head.id, fingerprint: .preview.fingerprint}')"
```
</RequestExample>

A release needs a repository that is public on GitHub now. A new release returns `201`, and unchanged results return `200`. If anything changed since the preview, it returns `409` with a fresh preview.

| Method | Route | Returns |
| --- | --- | --- |
| `GET` | `{repo}/releases/preview` | `{ preview, head, current, summaries? }`. `preview.settings` lists each setting's `key`, its `coverage` of approved tasks, and whether the app pre-ticks it (`ticked`) |
| `GET` | `{repo}/releases` | `{ releases, resultsSiteUrl }` |
| `POST` | `{repo}/releases/{id}/withdraw` | `{ release }`; the page falls back to the previous release |

A [repository group](/api-reference/create-benchmark#repository-groups) releases the same way at `/api/orgs/{org}/groups/{slug}/releases`. It publishes scores only, never tasks or transcripts. Released results are readable by anyone through the [Public Results API](/api-reference/overview).
