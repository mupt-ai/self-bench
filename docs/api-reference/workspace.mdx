The app at `https://app.selfbench.dev` exposes an authenticated JSON API. Create a key in **Settings → API Keys**; copy the `sbk_` secret when shown.

```bash
export SELFBENCH_API_KEY=sbk_…
curl https://app.selfbench.dev/api/me \
  -H "Authorization: Bearer $SELFBENCH_API_KEY"
```

A key acts as its owner, including workspace roles. `read` keys allow only `GET`; `write` keys can mutate what the owner can. Key creation and revocation require a browser session. Errors are JSON with an `error` field.

Repository routes use `/api/orgs/{org}/repos/{owner}/{name}`. Other useful routes:

| Method | Route | Purpose |
| --- | --- | --- |
| `GET`, `POST` | `/api/orgs/{org}/repos` | List or connect repositories |
| `PUT` | `/api/orgs/{org}/repos/{owner}/{name}/tasks/{runId}/{taskId}/review` | Approve or reject a task |
| `GET` | `/api/orgs/{org}/repos/{owner}/{name}/evaluations/comparisons` | List comparisons |
| `GET`, `POST` | `/api/orgs/{org}/credentials` | List or add workspace credentials |
| `GET` | `/v1/runs/{runId}/export` | Download a batch's Harbor tasks |

### OpenRouter Billing Access

Workspace admins can add an optional `managementKey` alongside an OpenRouter inference key, either in **Credentials → Add Provider** or with the API:

```bash
curl https://app.selfbench.dev/api/orgs/my-org/credentials \
  -H "Authorization: Bearer $SELFBENCH_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{"name":"OpenRouter","kind":"openrouter","value":"<inference-key>","managementKey":"<same-account-management-key>"}'
```

The management key is encrypted with that workspace credential, never returned by the API, and never passed to Harbor or a solver. It must belong to the inference key's OpenRouter account. Existing credentials can be replaced; existing runs retain their original credential references.

Jev pricing discovers generations in sessions proven by complete Pi response IDs, verifies nested calls against the same request and session, and uses full-precision generation charges. The archived accounting IDs and billing records support later audits. Costs include OpenRouter charges plus separately billed BYOK provider inference; they are not solely OpenRouter credit deductions. Missing billing access, incomplete transcripts, truncated analytics, unsettled records, or ambiguous accounting leave the price unknown, never a partial subtotal. Other harnesses currently cannot supply this Jev accounting.

The workspace API is separate from the anonymous [Public Results API](/api-reference/overview). For self-hosted deployments, replace the app origin with your own.
