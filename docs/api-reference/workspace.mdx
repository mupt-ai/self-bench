The app at `https://app.selfbench.dev` exposes an authenticated JSON API. Create a key in **Settings → API Keys**; copy the `sbk_` secret when shown.

```bash
export SELFBENCH_API_KEY=sbk_…
curl https://app.selfbench.dev/api/me \
  -H "Authorization: Bearer $SELFBENCH_API_KEY"
```

A key acts as its owner, including workspace roles. `read` keys allow only `GET`; `write` keys can mutate what the owner can. Key creation and revocation require a browser session. Errors are JSON with an `error` field.

Repository routes use `/api/orgs/{org}/repos/{owner}/{name}`. Other useful routes:

| Method | Route | Purpose |
| --- | --- | --- |
| `GET`, `POST` | `/api/orgs/{org}/repos` | List or connect repositories |
| `PUT` | `/api/orgs/{org}/repos/{owner}/{name}/tasks/{runId}/{taskId}/review` | Approve or reject a task |
| `GET` | `/api/orgs/{org}/repos/{owner}/{name}/evaluations/comparisons` | List comparisons |
| `GET` | `/api/orgs/{org}/credentials` | List workspace credentials |
| `GET` | `/v1/runs/{runId}/export` | Download a batch's Harbor tasks |

The workspace API is separate from the anonymous [Public Results API](/api-reference/overview). For self-hosted deployments, replace the app origin with your own.
